Full-stack demo: Vue 3 frontend + Python FastAPI backend + in-memory JSON data

Frontend

Vue 3 :3000

  • Axios (HTTP client)

FastAPI :8001

  • Python 3.11+
  • Pydantic v2 validation

Filter Data Flow

1

User selects a filter

FilterBar.vue dropdowns update shared refs in useFilters.js — e.g. selectedPeriod = "Q1-2025", selectedLocation = "San Francisco"

2

View reacts and fetches data

Each view watch()es filter refs. On change it calls getCurrentFilters() and triggers api.getOrders(filters)

3

HTTP request built

api.js builds URLSearchParams, omitting any 'all' values → GET /api/orders?warehouse=San+Francisco&month=Q1-2025

4

Backend filters in-memory data

apply_filters() sequences: warehouse (exact) → category (case-insensitive) → status (case-insensitive)
filter_by_month(): direct 2025-01 or quarter expansion Q1-2025 → [2025-01, 2025-02, 2025-03]

5

Pydantic validates the response

FastAPI serialises each item through its Pydantic model (e.g. Order) before returning JSON to the client

6

Vue re-renders

Response stored in ref (e.g. orders.value). Computed properties recalculate KPIs. v-for re-renders the table rows.

API Endpoints

warehousecategorystatusmonth
GET /api/orders/{id} Single order
GET /api/dashboard/summary KPIs: inventory value, low stock, pending orders, backlog count
warehousecategorystatusmonth
GET /api/demand Demand forecasts with trend (increasing / stable / decreasing)
GET /api/backlog Backlog items with computed has_purchase_order flag
GET /api/spending/summary Total spend, average order value
GET /api/spending/monthly Monthly spend breakdown
GET /api/spending/categories Spend by category
GET /api/spending/transactions Recent transaction list
GET /api/reports/quarterly Orders, revenue, fulfillment rate per quarter
GET /api/reports/monthly-trends Month-over-month order count and revenue
